# Данные проекта

Проект использует данные двух аналитических кейсов.

## Активность пользователей книжного сервиса

Файл `yandex_knigi_data.csv` содержит обезличенные данные пользователей Москвы и Санкт-Петербурга:

- `puid` — идентификатор пользователя;
- `city` — город пользователя;
- `hours` — суммарное время чтения и прослушивания книг.

Локальный файл не публикуется в репозитории. Для запуска первой части ноутбука его необходимо поместить в папку `data`.

## A/B-тест интернет-магазина

Используются два набора данных:

- `ab_test_participants.csv` — участники тестов, экспериментальные группы и типы устройств;
- `ab_test_events.zip` — пользовательские события и даты их совершения.

Данные A/B-теста загружаются непосредственно в ноутбуке из внешнего источника.

## Конфиденциальность

Все идентификаторы пользователей обезличены. Репозиторий не содержит персональных данных.
