# SQL-анализ продуктовых метрик

В папке находятся PostgreSQL-запросы для расчёта ключевых метрик сервиса «Яндекс Книги».

## Состав анализа

1. `01_top_authors_by_mau.sql` — топ-3 авторов по MAU за ноябрь 2024 года.
2. `02_top_content_by_mau.sql` — топ-3 произведений по MAU.
3. `03_cohort_retention.sql` — дневной retention пользователей, активных 2 декабря.
4. `04_average_ltv_by_city.sql` — средний LTV пользователей Москвы и Санкт-Петербурга.
5. `05_average_revenue_per_hour.sql` — MAU, суммарные часы и средняя выручка на час.

## Использованные возможности SQL

- `JOIN`;
- CTE;
- `COUNT(DISTINCT ...)`;
- агрегатные функции;
- оконная и когортная логика;
- работа с датами;
- расчёт продуктовых метрик;
- защита от деления на ноль.
