# Результаты обработки данных

При выполнении ноутбука в эту папку сохраняются промежуточные таблицы, подготовленные для анализа A/B-теста.

## Формируемые файлы

### `events_test_clean.csv`

Все события пользователей теста `interface_eu_test` после исключения участников конкурирующих экспериментов.

Количество строк в исходном анализе: 73 815.

### `relevant_events_clean.csv`

События регистрации и покупки, используемые для расчёта семидневной конверсии.

Количество строк в исходном анализе: 19 450.

## Примечание

CSV-файлы не публикуются в репозитории. Они автоматически создаются при последовательном выполнении ячеек ноутбука.
