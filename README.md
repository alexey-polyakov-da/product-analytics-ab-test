Проект по продуктовой аналитике и статистическому тестированию. Работа объединяет два кейса: сравнение активности пользователей книжного сервиса в Москве и Санкт-Петербурге и оценку A/B-теста нового интерфейса интернет-магазина BitMotion Kit.

**[Открыть ноутбук](notebooks/product_analytics_ab_test.ipynb)** · [Посмотреть SQL-запросы](sql/)

## Цели проекта

### Кейс 1. Активность пользователей книжного сервиса

Проверить гипотезу о том, что пользователи из Санкт-Петербурга проводят в среднем больше времени за чтением и прослушиванием книг, чем пользователи из Москвы.

### Кейс 2. A/B-тест нового интерфейса

Определить, повышает ли упрощённый интерфейс интернет-магазина конверсию зарегистрированных пользователей в покупателей и достигает ли рост целевого значения — не менее **3 процентных пунктов**.

## Кейс 1. Сравнение активности по городам

После удаления дубликатов в анализе осталось **8 540 пользователей**.

| Показатель | Москва | Санкт-Петербург |
|---|---:|---:|
| Пользователи | 6 234 | 2 306 |
| Средняя активность, часов | 10,88 | 11,26 |
| Медианная активность, часов | 0,92 | 0,88 |
| Стандартное отклонение | 36,85 | 39,83 |

Для сравнения средних использован односторонний t-тест Уэлча для независимых выборок с неравными дисперсиями.

| Показатель теста | Значение |
|---|---:|
| t-статистика | 0,4028 |
| p-value | 0,3436 |
| Уровень значимости | 0,05 |

Средняя активность в Санкт-Петербурге выше на 3,4%, однако различие **не является статистически значимым**. Оснований утверждать, что петербургские пользователи активнее московских, недостаточно.

## Кейс 2. A/B-тест BitMotion Kit

### Проверка качества эксперимента

В исходных данных находилось **10 850 пользователей**. Проверка показала:

- группы A и B соответствуют техническому заданию;
- первоначальное распределение близко к 50/50, признаков SRM нет (`p-value = 0,5778`);
- пересечений между группами одного теста нет;
- обнаружено 887 пользователей, одновременно участвовавших в конкурирующем тесте;
- после исключения пересечений осталось **9 963 пользователя**;
- очищенные группы сохранили равномерность: A — 4 952, B — 5 011 (`p-value = 0,6864`);
- распределение пользователей по устройствам в группах однородно.

### Достаточность выборки

Расчёт выполнен при следующих параметрах:

| Параметр | Значение |
|---|---:|
| Базовая конверсия | 30% |
| Минимально обнаруживаемый эффект | 3 п.п. |
| Мощность теста | 80% |
| Доверительная вероятность | 95% |
| Требуемый размер одной группы | 2 886 пользователей |
| Фактический размер группы A | 4 952 пользователя |
| Фактический размер группы B | 5 011 пользователей |

Фактическая выборка превышает минимально необходимую в обеих группах и достаточна для проведения статистического теста.

### Результаты A/B-теста

| Метрика | Группа A — контроль | Группа B — новый интерфейс |
|---|---:|---:|
| Посетители | 4 952 | 5 011 |
| Покупатели | 1 435 | 1 562 |
| Конверсия | 28,98% | 31,17% |

Конверсия увеличилась на **2,19 процентного пункта**. Изменение статистически значимо (`p-value = 0,0085`), поэтому улучшение нельзя объяснить случайными колебаниями. Однако целевой эффект в **3 процентных пункта** не достигнут.

## Итоговый вывод

Новая версия интерфейса положительно повлияла на конверсию: рост статистически подтверждён, но оказался меньше ожидаемого. Интерфейс можно принять для дальнейшего использования, одновременно продолжив UX-оптимизацию и последующие эксперименты для достижения целевого эффекта.

## Рекомендации

- Внедрить новый интерфейс как версию, показавшую статистически значимое улучшение.
- Не считать целевую гипотезу полностью подтверждённой: фактический прирост ниже 3 п.п.
- Продолжить исследование пользовательского пути и выявить этапы, ограничивающие рост конверсии.
- Для следующих экспериментов заранее фиксировать метрики, MDE, горизонт анализа и правила исключения пересечений.
- Контролировать параллельное участие пользователей в нескольких тестах.
